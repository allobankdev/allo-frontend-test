# Global Utilities

This directory houses global helper functions, shared formatting utilities, and common JavaScript/TypeScript functions that are reused across multiple features and pages throughout the application.

## Directory Structure

```text
src/
└── utils/
    ├── formatters.ts       # Global data formatters (currency, dates, numbers)
    ├── validators.ts       # Shared form and input validation rules
    ├── storage.ts          # LocalStorage / SessionStorage wrappers
    └── helpers.ts          # General-purpose utility functions (debounces, formatting, etc.)
```
