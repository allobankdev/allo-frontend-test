# Allo Bank Frontend Technical Assignment

Dalam assignment ini, kamu diminta untuk membuat sebuah website yang menampilkan rocket. Website ini hanya memiliki dua layar: layar daftar rocket dan layar detail rocket. Berikut adalah kebutuhannya:

### Kebutuhan Fungsional
- Sebagai user, saya ingin melihat daftar rocket di layar daftar rocket (tampilkan gambar rocket, nama rocket, dan deskripsi rocket)
- Sebagai user, saya ingin bisa memfilter rocket di layar daftar rocket
- Sebagai user, saya ingin bisa menambahkan rocket baru di layar daftar rocket
- Sebagai user, saya ingin bisa melihat detail rocket dengan mengklik rocket di layar daftar rocket (tampilkan gambar rocket, nama rocket, deskripsi rocket, biaya per peluncuran, negara, penerbangan pertama)

### Kebutuhan Non-Fungsional
- Gunakan Space-X API (https://github.com/r-spacex/SpaceX-API) untuk mengambil data rocket
- Implementasikan router
- Implementasikan state management
- Implementasikan lifecycle
- Membuat komponen terpisah akan menjadi nilai tambah
- UI states (Loading, Fail/Retry, dan Success)
- Tampilkan loading saat menunggu respons dari API
- Jika terjadi error, user dapat mencoba lagi dengan menekan tombol retry
- Tampilkan hasil saat respons API berhasil didapatkan

### Karakteristik Nice to Have
Desain responsif.
Kamu tidak perlu terlalu memikirkan detail desain, kami tidak menilai kemampuan artistikmu (untuk saat ini), fokuskan usahamu pada source code yang mudah dibaca/bersih/maintainable.
